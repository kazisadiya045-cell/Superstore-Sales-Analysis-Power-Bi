# Superstore Sales Analysis - Power Bi
##Interactive Power BI dashboard analyzing sales, profit, and regional performance. This project analyzes sales performance using Power BI.
The dashboard provides insights on revenue, profit, customer segments, and regional trends.
## Dataset
- Source: Superstore Sales Dataset
- Rows: ~10,000
- Columns: Order Date, Sales, Profit, Category, Region, Customer Segment.
## Tools Used
- Power BI
- Excel (Data Cleaning)
- DAX
## Steps Performed
- Data cleaning and handling null values
- Created calculated columns (Year, Month)
- Built DAX measures for Sales and Profit
- Designed interactive dashboards
## Key Insights
- Total sales increased year-over-year with highest growth in 2017.
- Technology category generated the highest profit.
- West region contributed maximum sales.
- Consumer segment accounted for the largest share of revenue.
